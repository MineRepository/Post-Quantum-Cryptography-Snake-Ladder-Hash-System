# Post-Quantum-Cryptography-Snake-Ladder-Hash-System
A custom secure hash system in Python based on Snake and Ladder logic, using message chunks, bit shifts and XOR.
This is my Final Year Project for BS Information Technology at the University of Sargodha. It is a custom hash system built in Python on Post-Quantum Cryptography concepts. 

## How it works
The user's message is divided into chunks of required bits, and each chunk acts as a dice moving on a virtual Snake and Ladder board. Final results goes through Bit shifts and XOR operations to generate the final hash, and the hash length can be set according to the user's requirement.

python main.py
